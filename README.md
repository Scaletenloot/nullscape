## About

Nullscape reimagines the End as a place of dread rather than decoration. Vast hollow caverns, towering void pillars and desolate stone plains stretch across the outer islands in muted greys and blacks. There is almost nothing alive out there, and that is entirely the point.

---

## Features

- Complete outer-End terrain overhaul with towering void formations
- Enormous hollow caverns and layered island structures
- Deliberately bleak, muted palette focused on atmosphere
- Datapack-driven — lightweight and highly compatible
- Pairs naturally with End structure and mob mods

## Installation

1. **Download** the JAR matching your Minecraft version from the table above.
2. **Install a mod loader** — Forge, Fabric or NeoForge for your exact game version.
3. **Place the `.jar`** into your `.minecraft/mods/` folder (create it if it is missing).
4. **Launch** Minecraft using the modded profile.
5. Verify **Nullscape** appears in the in-game mods list.

> **Tip:** if the game crashes on startup, you almost certainly mixed a Legacy JAR with a Modern
> Minecraft version, or are missing a required dependency. Check `latest.log` first.

## FAQ

**Q: Does it add mobs or items?**
A: No. Nullscape is purely terrain and atmosphere — pair it with a mob or structure mod for content.

**Q: Compatible with BetterEnd?**
A: They both regenerate End terrain; running one at a time is recommended.

**Q: Does it touch the dragon island?**
A: No, the central island stays vanilla.

**Q: Is it safe to add to an existing world?**
A: Yes in most cases — back the save up first, as you should with any mod addition.

**Q: Can I use it in a public modpack?**
A: Yes. Both builds are modpack-ready and require no additional setup.
